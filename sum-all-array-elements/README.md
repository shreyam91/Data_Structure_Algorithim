# Sum of Array

**[View Problem on GeeksforGeeks](https://www.geeksforgeeks.org/problems/sum-all-array-elements/)**

---

## Problem

Given an integer array arr[], return the sum of all elements of arr.

## Examples
### Example 1

**Input:**

```
arr[] = [1, 2, 3, 4]
```

**Output:**

```
10
```

**Explanation:**

1 + 2 + 3 + 4 = 10.

### Example 2

**Input:**

```
arr[] = [1, 3, 3]
```

**Output:**

```
7
```

**Explanation:**

1 + 3 + 3 = 7.

## Input Format
- arr[] = — INTEGER_ARRAY

## Constraints
- arr[] =: min_size 0, max_size 10^5, element_min_value 0, element_max_value 10^4

## Expected Complexity
- Time: O(n)
- Auxiliary Space: O(1)
